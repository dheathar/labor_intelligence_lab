## Abstract

LLMs extract nuanced, complex job features from unstructured postings.
Combines semantic chunking of job posting text with vector embeddings and
similarity-based retrieval. Prompt augmentation with contextual similarity
matching outperforms traditional NLP on fine-grained feature extraction.

## Key findings

- LLMs extract nuanced features traditional NLP misses
- Semantic chunking + vector retrieval improves accuracy
- Prompt augmentation with contextual similarity matching is key
