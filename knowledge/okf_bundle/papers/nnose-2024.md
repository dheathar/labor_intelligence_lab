## Abstract

Novel approach using similarity-based matching for occupational skill extraction.
Maps free-text job descriptions to ESCO taxonomy entries using nearest-neighbor
retrieval in a shared embedding space. Avoids need for task-specific fine-tuning.

## Key findings

- Nearest-neighbor retrieval competitive with fine-tuned classifiers
- Zero-shot generalization to new ESCO taxonomy versions
- Computationally efficient compared to generative approaches
