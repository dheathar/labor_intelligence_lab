## Abstract

Graph-based representation of skills and occupations used to enrich LLM
distillation for HR-specific tasks. Provides structured context from the
ESCO skill-occupation graph to improve distilled model performance on
job matching, skill extraction, and occupational classification.

## Key findings

- Skill-occupation graph context improves distillation outcomes
- Structured ESCO relationships complement unstructured text
- Smaller distilled models with graph context approach full LLM performance
