# EU-ALMPO


_EU Active Labour Market Policies Observatory_


The EU-ALMPO establishes the EU Active Labour Market Policies Observatory — an
AI-powered platform to reshape ALMP design, implementation and evaluation across
the EU. The observatory leverages online job posting crawling, administrative data,
and machine learning to provide policymakers, researchers, and employment services
with evidence-based tools for skills matching, workforce planning, and inclusive
labour market interventions.

## Countries

Greece, Italy, Poland, Spain, Germany, Denmark (Associated)

## Objectives

- Develop an analytical model and evaluation framework for ALMP effectiveness
- Conduct in-depth skills matching analysis across 5 partner countries
- Build an AI-powered ALMP knowledge repository with annotation tools
- Create a multi-source labour market analysis tool (OJA + admin data)
- Develop a CV-insights platform for personalised ALMP recommendations
- Run innovation experiments with practitioners and employment services
- Evaluate outcomes and produce policy recommendations for the EU

## Data sources

- Multi-country OJA crawler (12+ countries)
- ELSTAT LFS (Greece, quarterly + annual)
- INE EPA (Spain, monthly/quarterly)
- ISTAT RFL (Italy, monthly/quarterly)
- DYPA/Ergani register (Greece)
- SEPE register (Spain)
- NSZ Portal (Serbia)
- Eurostat Labour Market DB (REST + SDMX)
- ILOSTAT SDMX API (global)
- EU-LFS microdata (Eurostat)
