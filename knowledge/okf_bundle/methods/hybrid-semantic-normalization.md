## Description

The Cedefop/Eurostat Web Intelligence Hub approach for processing Online Job
Advertisements at scale. Combines rule-based normalisation with semantic
embedding-based matching to map free-text job requirements to ESCO
skills/occupations across European languages. Powers Skills-OVATE tool.
Presented at the Cedefop-Eurostat conference (Thessaloniki, May 2026).

## Strengths

- Production-proven at EU scale
- Multilingual (27 EU languages)
- Real-time processing pipeline
- ESCO-aligned output

## Weaknesses

- Proprietary Cedefop implementation details not fully published
- Requires substantial OJA data infrastructure
