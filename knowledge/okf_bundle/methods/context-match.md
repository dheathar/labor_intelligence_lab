## Description

Lightweight bi-encoder with contrastive learning for skill extraction from job postings.
Achieves state-of-the-art on skill extraction benchmarks at significantly lower
computational cost than generative approaches. Maps job text spans to ESCO skills.

## Strengths

- State-of-the-art skill extraction performance
- Computationally efficient (bi-encoder)
- Suitable for production deployment

## Weaknesses

- English-focused
- Requires ESCO as target taxonomy
