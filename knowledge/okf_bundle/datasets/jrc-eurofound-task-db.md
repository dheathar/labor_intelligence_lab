## Description

Occupational task profiles derived from representative European worker surveys (EWCS and
other Eurofound sources). Each occupation has a structured task profile across dimensions:
intellectual/analytical tasks, social/communication tasks, manual/physical tasks, routine
vs. non-routine, autonomous vs. supervised work. Enables OJA task signal validation.
