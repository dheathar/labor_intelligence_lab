## Description

The Greek national job register. DYPA's Ergani system collects all formally
registered job vacancies and labour demand. Integrated with the Labour Market
Diagnostic Mechanism for real-time monitoring using big data analytics.
Skills classified using ESCO taxonomy. Primary source for Greek labour demand
intelligence. Access primarily through website portal and diagnostic tool;
no public API documented.

## Key variables

- job vacancy count by sector and region
- skill requirements (ESCO-mapped)
- registered unemployment profiles
- labour demand diagnoses by occupation
