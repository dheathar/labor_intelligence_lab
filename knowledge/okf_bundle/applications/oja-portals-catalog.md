## Description

Catalog of key Online Job Advertisement portals by country/region. These are
the primary sources for labor demand intelligence via OJA analysis. Each portal
can be scraped (where permitted) or accessed via API for skill extraction,
occupational demand analysis, and real-time labor market intelligence.
